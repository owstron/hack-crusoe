Privacy Policy

Last updated: October 17, 2026

This policy describes how information is handled when you visit the AdCampaigner website or use the AdCampaigner project. AdCampaigner is an experimental demonstration, not a production advertising service.

Website visits

The website is a static GitHub Pages site. It does not provide accounts, forms, or advertising features. GitHub may process technical information such as request and security logs when it hosts and serves the site; please refer to GitHub’s Privacy Statement for its practices.

Using the project

The project runs campaign experiments in a simulator. If you run it, information you provide and campaign inputs or outputs may be processed by the AI model and research services configured for that run. Those services handle information under their own privacy terms. Do not use real customer, personal, or confidential advertising data with this experimental project.

Information sharing and retention

The project does not operate a central user account or data collection service. Information handled by third-party hosting, model, or research providers is subject to those providers’ policies and settings. If you run the project yourself, generated logs and files are stored in your local environment unless you choose to share them.

Changes to this policy

This policy may be updated as the project changes. The date above indicates when it was last revised.

Contact

For questions about this policy or the project, open an issue in the AdCampaigner GitHub repository.
